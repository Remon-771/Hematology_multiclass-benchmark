# Changelog

## 1.0.0 — Initial release

- Packaged the 12,618-record CBC dataset (unmodified) with a data dictionary and SHA-256 fingerprint.
- Refactored the study notebook into the `cbcbench` package and ten numbered, command-line pipeline scripts.
- Included the generated tables (`results/`), figures (`figures/final/`), methodology diagram and the final model pipeline (`models/`).
- Added dataset-contract, leakage-protocol and committed-results tests, a release-audit script, a SHA-256 file manifest and CI.
