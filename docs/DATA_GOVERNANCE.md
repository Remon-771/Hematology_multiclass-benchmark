# Data stewardship and access

## Responsible research use
* The dataset is intended for research on CBC-pattern classification and for reproducing this study.
* The class labels are CBC-pattern categories, not confirmed clinical diagnoses; do not use trained models for patient care.
* Do not attempt to re-identify records or link them to other data sources.
* Any revision of the data must be versioned with updated checksums (`data/README.md`, `FILE_MANIFEST_SHA256.txt`).

## Items for the authors to complete before public release
* Ethics committee name and approval/reference number; consent status (obtained or waived); de-identification statement (notebook §23).
* Data provenance: study population and setting (retrospective/prospective, single/multi-centre), inclusion/exclusion criteria, and who assigned/validated the class labels.
* Licence for code and data, repository URL and DOI.
